KATHANGALI DIGITAL SKILLS PROJECT WEBSITE

FILES
- index.html = website page
- style.css = design and mobile responsiveness

TO USE
1. Keep both files in the same folder.
2. Open index.html in a browser to preview it.
3. Before publishing, replace the contact placeholder with your real phone, email and WhatsApp details.
4. Add project photos when available.
5. Upload the folder to a web host.

The site is intentionally simple, fast, mobile-friendly and suitable for presenting the project to community partners and donors.
